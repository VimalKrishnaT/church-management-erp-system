# Church Management ERP System

## Overview
A full-stack Enterprise Resource Planning (ERP) application designed to manage church financial records and administrative information efficiently.

## Technologies Used
- **Backend:** Python, Django, Django REST Framework
- **Frontend:** React
- **Database:** MySQL
- **API:** REST APIs

## Key Features
- **Bill Management:** Manage church bills and related financial information.
- **Receipt Management:** Maintain receipt records and payment details.
- **Dues Management:** Support dues records and bulk dues collection.
- **Family and Member Management:** Organize family and member information.
- **Financial Reporting:** Support financial record review and reporting.
